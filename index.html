What it catches

The holes vibe coding leaves behind

These are the issues we see again and again in AI-generated apps — the kind that turn one copied prompt into a data breach.

SQLI

SQL injection

User input dropped straight into a query string instead of a prepared statement.

KEYS

Hardcoded secrets

Stripe, AWS, OpenAI and GitHub keys pasted right into the source.

EXEC

Command execution

eval, exec and shell_exec fed with request data.

XSS

Cross-site scripting

innerHTML and echoed input that lets attackers run their own scripts.

AUTH

Open admin & routes

Admin pages and dangerous endpoints with no login check in front of them.

HASH

Weak password hashing

md5 / sha1 for passwords — cracked in seconds.

CONF

Debug & default creds

Debug mode on in production, root DB users with blank passwords.

CORS

Wide-open CORS

Access control set to *, letting any site call your API.
