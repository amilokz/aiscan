Paste your .env (or any KEY=VALUE config) and this tool flags which entries are real secrets that must never reach Git. Everything runs in your browser — nothing is sent anywhere.

Paste your .env

What it checks

It scans each line for values that look like real API keys and tokens (Stripe, AWS, Google, GitHub, Slack, SendGrid, JWTs and database connection strings), and for key names that imply a secret — SECRET, PASSWORD, TOKEN, API_KEY. Placeholder values are treated as safe.

The rule

No real .env should ever be committed. Keep one .env.example with placeholders, and add .env to your .gitignore.

FAQ

Is it safe to paste my .env here?

Yes. The check runs entirely in your browser with JavaScript; nothing is uploaded or stored. You can disconnect from the internet and it still works.

Should I ever commit a .env file?

No. Commit a .env.example with placeholder values so teammates know which variables are needed, and keep the real .env git-ignored. Store production secrets in your host environment settings.
